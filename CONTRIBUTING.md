# Contributing

## Code contributions

Before submitting code, tests, build configuration or technical documentation, read [the Code Contributor Agreement v1.0](CONTRIBUTOR-AGREEMENT.md). Confirm acceptance in your pull request or in a written message to Faey Umbrea on [Discord](https://discord.com/invite/WfMaKPPdeM) or at licensing@void.monster.

Include this statement when you accept it:

> I have read and accept the Void Monster Open Source Code Contributor Agreement v1.0 for the contributions in this pull request.

Acceptance covers the contributions identified in that submission. It does not apply retroactively to earlier work. Third-party material retains its own licence; identify it and its licence separately.

Code contributions must follow the [Foundry VTT AI Content Policy](https://foundryvtt.com/article/ai-policy/). Unreviewed AI-generated portions are not accepted. You must personally review and be able to understand, explain, modify and maintain all code you submit.

Describe what your change does and how you checked it. Follow the repository's existing code style and run its available checks before submitting.

## Translation contributions

For translation contributions, follow the translation instructions in the [README](README.md). The code agreement does not replace the separate translation agreement.
